# 고객 미팅 준비판

고객 미팅(국내·해외)을 준비할 때 팀 할 일과 미팅 기록을 한 화면에서 보는 웹입니다. 녹음·회의록을 AI로 요약·공지·보고와 할 일로 정리합니다. 데이터는 구글 시트에 저장합니다.

- 화면 주소: GitHub Pages (저장소 Settings → Pages 에 표시)
- 화면의 고객·담당·일정은 예시 데이터입니다.

## 1. 화면

| 화면 | 내용 |
|---|---|
| 홈 | 미팅 D-day, 숫자 3개(남은 할 일 · 기한 지남 · 3일 안 마감), 오늘 챙길 일, 최근 기록, 「현황 공지 복사」 |
| 미팅 기록 | 녹음(글자로 받아 적기) · 회의록 붙여 넣기 · 파일 넣기(엑셀·CSV·워드·txt) → AI 정리 → 요약 · 공지 · 보고 복사, 할 일 골라 넣기. 방금 넣은 기록 1건만 보임 |
| 기록함 | 지난 기록을 날짜별로 모아 봄(최근이 위). 이번 미팅/모든 미팅, 검색. 줄을 누르면 요약 · 공지 · 보고 · 원문이 펼쳐짐 |
| 할 일 | 할 일 · 담당 · 기한 · 완료 체크 한 줄 목록 (기한 지남 → 남은 일 → 완료) |
| 고객 | 회사 · 성함 · 직급 · 연락처 · 이메일 · 메모 카드. 미팅 정보에서 참석 고객을 고르면 홈 미팅 띠에 이름이 나옴 |

## 2. 쓰는 법

| 하려는 일 | 방법 |
|---|---|
| 보기 | 주소만 열면 됩니다. 30초마다 시트의 최신 내용으로 바뀝니다 |
| 추가·수정·삭제 | 오른쪽 위 「편집하기」 → 팀 비밀번호. 이 브라우저에서는 다시 묻지 않습니다. 여러 사람이 쓰는 PC에서는 맨 아래 「편집 잠그기」 |
| 회의록 AI 정리 | 「편집하기」 후 「미팅 기록」 → 회의록 붙여 넣기 → 「저장하고 AI 정리」 → 「방금 넣은 기록」에 요약 · 공지 · 보고와 할 일이 바로 나옴(창 없음). Claude API 키가 있으면 Claude가 정리하고, 없으면 화면 안 자동 정리(담당 이름·「~까지」 기한·확정/결정 문장을 규칙으로 뽑음, AI 아님). 같은 미팅에 같은 내용이 이미 정리돼 있으면 그 결과를 다시 씀 → 할 일 골라 넣기 |
| 미팅 녹음 | 「미팅 기록」 → 「녹음 시작」 (Chrome·Edge). 말한 내용이 글자로 쌓이고 「녹음 1, 2, 3…」으로 저장됩니다 |

## 3. 처음 설정 (관리자, 한 번)

1. 구글 시트를 열고 확장 프로그램 → Apps Script
2. `apps-script/Code.gs` 내용을 붙여 넣고 저장
3. 프로젝트 설정 → 스크립트 속성 → `WRITE_KEY` = 팀 편집 비밀번호
   - AI 바로 정리: `ANTHROPIC_API_KEY` = Claude Console(platform.claude.com) → API Keys 에서 만든 키. (선택) `CLAUDE_MODEL` 모델 ID, 비워 두면 `claude-opus-5-5`
4. 배포 → 새 배포 → 유형 「웹 앱」, 실행 계정 「나」, 액세스 권한 「모든 사용자」 → 배포 → 권한 승인
5. 웹 앱 주소(`…/exec`)를 `config.js` 의 `API_URL` 에 넣기

- 비밀번호를 바꿀 때는 3의 값만 바꿉니다(다시 배포할 필요 없음).
- `Code.gs` 를 고친 뒤에는 배포 → 배포 관리 → 수정(연필) → 버전 「새 버전」 → 배포 (주소는 그대로)

## 4. 데이터 (구글 시트)

쓰는 탭: 미팅 · 고객 · 팀 할 일 · 기록 (파일로 넣은 자료는 「기록」 탭에 종류 「자료」로 저장)

- 1행 머리글 이름은 바꾸지 않습니다(열 순서는 바꿔도 됨). 없는 열은 웹 화면이 저장할 때 만듭니다.
- 시트에 직접 줄을 넣어도 됩니다. ID 칸은 비워 두면 자동으로 채워집니다.
- 할 일 완료는 「상태」 칸이 「완료」인 줄입니다.

## 5. 주의

- 보기는 공개입니다. 화면 주소나 웹 앱 주소를 아는 사람은 시트 내용을 읽을 수 있습니다. 실제 고객 연락처·계약 조건 같은 민감한 내용은 넣지 않거나, 읽기에도 비밀번호를 거는 방식으로 바꾼 뒤 씁니다.
- 편집 비밀번호는 이 저장소에 넣지 않습니다(Apps Script 스크립트 속성에만 둠).
- 녹음 받아쓰기는 브라우저 음성 인식을 씁니다. Chrome은 구글, Edge는 마이크로소프트 서버에서 글자로 바뀝니다.
- AI 정리는 Claude API로 하므로 회의록 내용이 Anthropic으로 보내집니다. 사용량만큼 API 요금이 듭니다.
- AI 정리는 편집 비밀번호를 넣은 사람만 부를 수 있습니다(키 사용량 보호). API 키는 저장소에 넣지 않습니다(Apps Script 스크립트 속성에만 둠).
